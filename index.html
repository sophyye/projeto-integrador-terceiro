ATIVIDADE 01

🔐 Cofre Digital de Saúde e Emergência Médica

Objetivo

Criar um programa capaz de armazenar informações fictícias de saúde e emergência, permitindo que esses dados sejam protegidos por uma senha.

Informações armazenadas

  • Nome;
  • Tipo sanguíneo;
  • Alergias;
  • Medicamentos utilizados;
  • Contato de emergência;
  • Nome e telefone do médico;
  • Plano de saúde.

Como funciona?

O usuário informa os dados fictícios e cria uma senha. O programa organiza as informações em formato JSON e utiliza recursos de criptografia educacional para proteger o conteúdo. Para acessar os dados novamente, é necessário informar a senha correta. O sistema também verifica a integridade das informações.

Recursos utilizados

  • input: recebe informações do usuário.
  • getpass: permite receber uma senha sem exibi-la normalmente.
  • json: organiza os dados.
  • hashlib: fornece funções de resumo criptográfico e derivação de chaves.
  • hmac: ajuda a verificar a integridade dos dados.
  • base64: transforma dados binários em texto, mas não é criptografia.
  • XOR: operação lógica utilizada no exemplo educacional de proteção.

Etapas do programa

  1. Solicitar as informações fictícias.
  2. Solicitar a criação e confirmação da senha.
  3. Organizar os dados em formato JSON.
  4. Gerar chaves derivadas da senha.
  5. Proteger os dados e salvar o arquivo.
  6. Solicitar a senha para abrir o cofre.
  7. Verificar a integridade e mostrar os dados se a senha estiver correta.

Testes realizados

No teste com senha incorreta, o acesso foi recusado. No teste com a senha correta, as informações armazenadas puderam ser visualizadas.

Observação de segurança: este é um projeto didático. A combinação de XOR e outros recursos demonstrados não representa um sistema profissional de criptografia. Não utilize dados reais de saúde ou senhas pessoais neste exemplo.

PROJETO 01

💡 Matriz de LEDs 8×8

Componentes e recursos

  • Arduino Uno;
  • Matriz de LEDs 8×8;
  • Biblioteca LedControl;
  • Biblioteca MatrizLed.

Funcionamento

A matriz possui 64 pontos luminosos organizados em oito linhas e oito colunas. Cada ponto pode ser ligado ou desligado para formar desenhos e símbolos.

No projeto, uma sequência binária representa uma figura, enquanto a biblioteca controla os LEDs e permite a exibição de uma frase em movimento: "Como estou me sentindo".

Interpretação dos valores

  • 1: LED ligado.
  • 0: LED desligado.

Código utilizado

#include <LedControl.h>
#include <MatrizLed.h>

#include <Arduino.h>
#include <Wire.h>
#include <SoftwareSerial.h>

LedControl led = LedControl(8, 10, 9, 1);
MatrizLed displayLCD;

String isturnOn, figure2, isturnOn_2, figure2_2;

String figure_1 = "0011110001000010101010011000010110000101101010010100001000111100";

void _delay(float seconds) {
  long endTime = millis() + seconds * 1000;
  while(millis() < endTime) _loop();
}

void setup() {
  for(int i = 0; i < 1 + 1; i++){
    led.shutdown(i, false);
  }

  displayLCD.begin(8,10,9,1);
  displayLCD.rotar(false);

  while(1) {
    displayLCD.borrar();
    displayLCD.escreverFraseScroll("Como estou me sentindo", 50);

    for (int counter = 0; counter < 8; counter++) {
      figure2 = figure_1.substring(counter * 8, (counter + 1) * 8);

      for (int counter2 = 0; counter2 < 8; counter2++) {
        isturnOn = figure2.substring(counter2, counter2 + 1);

        if (isturnOn == "1") {
          led.setLed(1 - 1, counter, 7 - counter2, true);
        } else {
          led.setLed(1 - 1, counter, 7 - counter2, false);
        }
      }
    }

    _delay(3);
    _loop();
  }
}

void _loop() {
}

Relação com acessibilidade

Matrizes de LEDs podem apresentar símbolos e mensagens visuais. Esse recurso pode complementar avisos sonoros em ambientes públicos, permitindo que informações sejam transmitidas por mais de um meio.

PROJETO 02

🔔 Botão, LED e buzzer — Código Morse

Componentes

  • Arduino Uno;
  • Buzzer conectado ao pino 2;
  • Botão conectado ao pino 3;
  • LED conectado ao pino 4.

Funcionamento

O botão funciona como entrada. Quando pressionado, o LED acende e o buzzer emite um som de frequência de 800 Hz. Quando o botão é solto, o LED apaga e o buzzer para de emitir som.

Código utilizado

/* Programa: Código Morse */

/* Definindo os pinos do Buzzer, botão e LED */
int buzzer = 2;
int botao = 3;
int LED = 4;

void setup()
{
  /* Define os pinos do LED e Buzzer como saída */
  pinMode(buzzer, OUTPUT);
  pinMode(LED, OUTPUT);

  /* Define o botão como entrada e ativa o resistor interno */
  pinMode(botao, INPUT_PULLUP);
}

void loop()
{
  /* Verifica se o botão está pressionado */
  if (digitalRead(botao) == LOW) {
    digitalWrite(LED, HIGH);
    tone(buzzer, 800);
  }

  /* Caso contrário, desliga o LED e o som */
  else {
    digitalWrite(LED, LOW);
    noTone(buzzer);
  }
}

O que é o código Morse?

O código Morse é um sistema de comunicação que representa letras e números por combinações de sinais curtos e longos. Um exemplo conhecido é o sinal SOS, representado por três sinais curtos, três longos e três curtos.

Neste circuito, o código controla um som contínuo enquanto o botão está pressionado. Ele não gera automaticamente letras, pontos ou traços do código Morse.

Relação com acessibilidade

A combinação de luz e som demonstra como um alerta pode utilizar diferentes sentidos para transmitir uma informação. Em soluções acessíveis, é importante oferecer alternativas para pessoas com diferentes necessidades sensoriais.

PROJETO 03

🖥️ Display LCD 16×2

Componentes

  • Arduino Uno;
  • Display LCD 16×2;
  • Potenciômetro;
  • Resistor e fios de ligação.

Funcionamento

O display LCD possui duas linhas, com capacidade para apresentar até 16 caracteres em cada uma. O programa apresenta mensagens iniciais e também recebe caracteres pela comunicação serial.

Organização dos pinos

RS no pino 12, E no pino 11 e os pinos de dados D4, D5, D6 e D7 ligados, respectivamente, aos pinos 5, 4, 3 e 2 do Arduino.

Código utilizado

#include <LiquidCrystal.h>

// Define os pinos do LCD:
// RS, E, D4, D5, D6, D7
LiquidCrystal lcd(12, 11, 5, 4, 3, 2);

void setup()
{
  Serial.begin(9600);

  lcd.begin(16, 2);
  lcd.clear();

  lcd.setCursor(0, 0);
  lcd.print("but cute");

  lcd.setCursor(0, 1);
  lcd.print("eu amo 67...");
}

void loop()
{
  if (Serial.available() > 0)
  {
    char cr = Serial.read();

    if (cr == '%')
    {
      lcd.clear();
      lcd.setCursor(0, 0);
    }
    else if (cr == '>')
    {
      lcd.setCursor(0, 1);
    }
    else
    {
      lcd.print(cr);
    }
  }
}

Comandos especiais

  • %: limpa o display e posiciona o cursor na primeira linha.
  • >: posiciona o cursor na segunda linha.
  • Outros caracteres: são exibidos na posição atual do cursor.

Relação com acessibilidade

Displays podem apresentar instruções e informações escritas, auxiliando na comunicação em determinados ambientes. Entretanto, telas pequenas não substituem recursos como letras ampliadas, leitores de tela e outras formas de comunicação acessível.

DISCIPLINA 03

🔊 Física e TecnoCiência

O som, o ambiente escolar e a acessibilidade acústica.

Introdução

Nesta atividade, investigamos os níveis de som em diferentes espaços da escola utilizando um aplicativo de medição sonora instalado em um smartphone.

O objetivo foi observar como as características dos ambientes e as atividades realizadas neles podem influenciar os níveis sonoros, relacionando os resultados à concentração, ao conforto e à acessibilidade.

1. O que é o som?

O som é uma onda mecânica produzida por vibrações. Para se propagar, precisa de um meio material, como o ar, a água ou os sólidos. Por isso, não se propaga no vácuo.

No ar, o som se propaga por variações de pressão, formando regiões de compressão e rarefação.

Frequência

A frequência representa o número de oscilações por segundo e é medida em hertz (Hz). Ela está relacionada à percepção de sons graves e agudos.

  • Frequência baixa: som grave.
  • Frequência alta: som agudo.

Intensidade sonora

A intensidade está relacionada à energia transportada pela onda sonora. Na percepção, está associada à sensação de som mais fraco ou mais forte.

O nível sonoro é frequentemente expresso em decibéis (dB), utilizando uma escala logarítmica.

Frequência e intensidade são características diferentes: frequência está relacionada a grave e agudo; intensidade, à percepção de fraco e forte.

2. Audição e efeitos do som

A audição envolve diferentes estruturas do ouvido. O som chega ao ouvido externo, provoca vibrações no tímpano, passa pelos ossículos e chega à cóclea, onde células sensoriais ajudam a transformar as vibrações em sinais enviados ao cérebro.

Faixa de audição humana

A faixa de audição humana é geralmente apresentada como aproximadamente 20 Hz a 20.000 Hz, mas pode variar entre pessoas e com a idade.

Exposição ao ruído

Sons muito intensos ou exposição prolongada a níveis elevados podem prejudicar a audição. O excesso de ruído também pode atrapalhar a concentração, a compreensão da fala e o processo de aprendizagem.

Os efeitos dependem de fatores como intensidade, duração da exposição e características individuais.

3. Metodologia da pesquisa

Foram realizadas medições em seis espaços da escola, utilizando um aplicativo de decibelímetro em um smartphone. Os valores registrados correspondem às médias apresentadas pelo aplicativo durante as observações.

Durante a coleta, foram anotados o local, o horário, o valor médio do som e as condições observadas no ambiente.

As medições foram observacionais. Não foi necessário provocar ruídos, interromper aulas ou gravar conversas. Os valores são estimativas do aplicativo, não uma avaliação acústica profissional.

5. Análise dos resultados

O maior valor registrado foi no pátio da escola, com 81 dB. Em seguida, apareceram a quadra coberta, com 75 dB, e o corredor das salas, com 71 dB.

Esses espaços apresentavam maior circulação de pessoas, conversas ou atividades acontecendo no momento da medição.

A sala de aula apresentou 51 dB, enquanto a biblioteca e o refeitório registraram 50 dB cada. Na biblioteca, as pessoas estavam quietas e o refeitório estava vazio.

Os resultados sugerem que as atividades e as condições de cada espaço podem influenciar os níveis sonoros. Entretanto, como as medições foram realizadas em um único período, não é possível afirmar que esses valores se repetem em todos os dias ou horários.

6. Limitações da pesquisa

O microfone de um smartphone e o aplicativo de decibelímetro não possuem necessariamente a mesma precisão de um equipamento profissional calibrado.

A distância do aparelho em relação às fontes sonoras, sua posição, as características do ambiente e o próprio aplicativo podem influenciar os resultados.

Portanto, os valores devem ser interpretados como estimativas para comparação entre os locais observados, e não como medições técnicas certificadas.

7. Ruído, inclusão e acessibilidade

Os ambientes sonoros podem ser percebidos de maneiras diferentes pelas pessoas. Algumas pessoas autistas, por exemplo, podem apresentar maior sensibilidade a determinados sons. Isso não significa que todas as pessoas autistas tenham a mesma experiência.

Conversas simultâneas, reverberação e ruídos inesperados podem causar desconforto ou dificultar a concentração de algumas pessoas.

Por isso, a acessibilidade também deve considerar o ambiente acústico e oferecer alternativas para diferentes necessidades sensoriais.

8. Propostas de melhoria para a escola

1. Materiais de absorção sonora

Avaliar a instalação de materiais adequados para absorver parte do som em locais com muita reverberação, como a quadra e o refeitório. Isso pode melhorar o conforto acústico.

2. Organização das atividades

Organizar horários e atividades para evitar a concentração de muitas fontes de ruído no mesmo espaço e fechar portas de salas quando isso for adequado ao funcionamento das aulas.

3. Espaço tranquilo

Disponibilizar um espaço mais silencioso, com identificação visual, para pessoas que precisem de um ambiente com menos estímulos sonoros.

4. Avisos visuais

Complementar avisos sonoros com placas, mensagens escritas ou sinais luminosos. Dessa maneira, a informação pode ser transmitida por diferentes meios.

9. Uso da Inteligência Artificial

A Inteligência Artificial pode auxiliar na explicação de conceitos físicos, na organização dos resultados e na elaboração de propostas de melhoria.

Entretanto, as informações precisam ser verificadas. Neste trabalho, as medições foram realizadas pelo grupo com o aplicativo de smartphone. A IA foi utilizada como apoio para compreender e organizar o conteúdo, não para substituir a coleta de dados.

Conclusão da disciplina

A pesquisa permitiu observar que os níveis sonoros variam entre os ambientes da escola e podem estar relacionados às atividades realizadas em cada espaço.

Também foi possível compreender que o conforto acústico faz parte da acessibilidade. Ambientes que consideram diferentes necessidades sensoriais podem favorecer a concentração, a comunicação, a participação e a qualidade de vida.

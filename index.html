ATIVIDADE 1

🔐 Cofre Digital de Saúde e Emergência Médica

Objetivo

Demonstrar como informações importantes para uma situação de emergência podem ser organizadas em um arquivo protegido por senha.

Como funciona

O programa solicita informações como nome, tipo sanguíneo, alergias, medicamentos, contato de emergência, médico, telefone do médico e plano de saúde. Depois, solicita a criação e a confirmação de uma senha.

PBKDF2-HMAC-SHA256Deriva uma chave a partir da senha e de um salt.
SHA-256Função hash utilizada no processo de derivação e no fluxo didático.
HMACPermite verificar se o conteúdo armazenado foi alterado.
Base64 e JSONRepresentação textual e organização dos dados.

Bibliotecas utilizadas

  • getpass: recebe a senha sem exibi-la na tela.
  • json: organiza os dados em estrutura de texto.
  • os: auxilia em operações e geração de salt.
  • base64: codifica os dados em uma representação textual.
  • hashlib: disponibiliza funções de hash e derivação de chave.
  • hmac: calcula e confere um código de autenticação.
Importante sobre segurança: a versão didática descrita utiliza uma transformação XOR com SHA-256, além de Base64. Isso não equivale a uma criptografia profissional autenticada. É um protótipo escolar: não utilize dados médicos ou pessoais reais e não o use para proteger informações importantes.

Testes relatados

Na atividade, a tentativa com senha incorreta foi rejeitada. Com a senha correta, os dados armazenados foram apresentados. O código Python original deve ser anexado ou conferido com o arquivo do Colab antes da entrega; esta página explica o funcionamento sem inventar uma versão original.

PROJETO 1

▦ Matriz de LED 8×8

A matriz de LED é composta por pequenos pontos luminosos organizados em linhas e colunas. A programação permite acender ou apagar cada ponto para formar imagens e símbolos.

Componentes utilizados

  • Arduino Uno;
  • Matriz de LED 8×8;
  • Bibliotecas LedControl e MatrizLed;
  • Conexões nos pinos 8, 10 e 9.

Funcionamento

O programa apresenta a frase “Como estou me sentindo” em movimento e utiliza uma sequência binária de 64 posições para formar uma figura na matriz. O valor 1 representa um LED aceso e o valor 0 representa um LED apagado.

▧Imagem da matriz de LEDAdicione aqui uma captura real da simulação no Tinkercad.
Visualizar código utilizado 
#include <LedControl.h>
#include <MatrizLed.h>

#include <Arduino.h>
#include <Wire.h>
#include <SoftwareSerial.h>

LedControl led = LedControl(8, 10, 9, 1);
MatrizLed displayLCD;

String isturnOn, figure2, isturnOn_2, figure2_2;

String figure_1 = "0011110001000010101010011000010110000101101010010100001000111100";

void _delay(float seconds) {
  long endTime = millis() + seconds * 1000;
  while(millis() < endTime) _loop();
}

void setup() {
  for(int i = 0; i < 1 + 1; i++){
    led.shutdown(i, false);
  }

  displayLCD.begin(8,10,9,1);
  displayLCD.rotar(false);
  while(1) {
    displayLCD.borrar();
    displayLCD.escribirFraseScroll("Como estou me sentindo", 50);

    for (int counter = 0; counter < 8; counter++) {
      figure2 = figure_1.substring(counter * 8, (counter + 1) * 8);
      for (int counter2 = 0; counter2 < 8; counter2++) {
        isturnOn = figure2.substring(counter2, counter2 + 1);
        if (isturnOn == "1") {
          led.setLed(1 - 1, counter, 7 - counter2, true);
        } else {
          led.setLed(1 - 1, counter, 7 - counter2, false);
        }
      }
    }
    _delay(3);
    _loop();
  }
}

void _loop() {
}
PROJETO 2

♫ Circuito de botão, LED e buzzer

Este circuito utiliza um botão para controlar simultaneamente um LED e um buzzer. Ele demonstra uma forma simples de produzir sinais visuais e sonoros.

Componentes utilizados

  • Arduino Uno;
  • Buzzer no pino 2;
  • Botão no pino 3;
  • LED no pino 4.

Funcionamento observado no código

Quando o botão é pressionado, o LED acende e o buzzer emite um som contínuo. Quando o botão é solto, o LED apaga e o som para.

Relação com o código Morse: o código Morse utiliza combinações de sinais curtos e longos para representar letras e números. O circuito desenvolvido demonstra um sinal sonoro e luminoso acionado por botão, mas não codifica automaticamente mensagens em Morse.

Como exemplo de representação em Morse, SOS corresponde a três sinais curtos, três longos e três curtos.

▧Imagem do circuito com buzzerAdicione aqui uma captura real da simulação no Tinkercad.
Visualizar código utilizado 
/* Programa: Código Morse */
/* Definindo os pinos do Buzzer, botão e LED */
int buzzer = 2;
int botao = 3;
int LED = 4;

void setup()
{
  /* Define os pinos do LED e Buzzer como saída */
  pinMode(buzzer, OUTPUT);
  pinMode(LED, OUTPUT);

  /* Define o pino do botão como entrada e ativa o resistor interno */
  pinMode(botao, INPUT_PULLUP);
}

void loop()
{
  /* Verifica se o botão está pressionado e então liga o LED e emite o som */
  if (digitalRead(botao) == LOW) {
    digitalWrite(LED, HIGH);
    tone(buzzer, 800);
  }

  /* Senão desligue o LED e pare o som */
  else {
    digitalWrite(LED, LOW);
    noTone(buzzer);
  }
}
PROJETO 3

▤ Display LCD 16×2

O display LCD 16×2 permite apresentar mensagens em duas linhas, com até 16 caracteres por linha. Pode ser utilizado para exibir informações de maneira visual.

Componentes utilizados

  • Arduino Uno;
  • Display LCD 16×2;
  • Potenciômetro;
  • Resistor e fios de conexão.

Funcionamento

O programa inicializa o display e apresenta duas mensagens. Depois, pode receber caracteres pela comunicação serial: o caractere % limpa a tela e posiciona o cursor na primeira linha; o caractere > posiciona o cursor na segunda linha; outros caracteres são exibidos no LCD.

▧Imagem do display LCDAdicione aqui uma captura real da simulação no Tinkercad.
Visualizar código utilizado 
#include <LiquidCrystal.h>

// Define os pinos do LCD:
// RS, E, D4, D5, D6, D7
LiquidCrystal lcd(12, 11, 5, 4, 3, 2);

void setup()
{
  Serial.begin(9600);
  lcd.begin(16, 2);
  lcd.clear();
  lcd.setCursor(0, 0);
  lcd.print("but cute");
  lcd.setCursor(0, 1);
  lcd.print("eu amo 67...");
}

void loop()
{
  if (Serial.available() > 0)
  {
    char cr = Serial.read();

    if (cr == '%')
    {
      lcd.clear();
      lcd.setCursor(0, 0);
    }
    else if (cr == '>')
    {
      lcd.setCursor(0, 1);
    }
    else
    {
      lcd.print(cr);
    }
  }
}

Física e TecnoCiência

Ciência do som: audição, acessibilidade e qualidade de vida.

INVESTIGAÇÃO CIENTÍFICA

O ambiente sonoro da escola

Uma análise dos níveis sonoros em diferentes espaços escolares e de sua relação com o conforto e a inclusão.

🔊 O que é o som?

O som é uma onda mecânica produzida por vibrações. Ele precisa de um meio material, como o ar, a água ou sólidos, para se propagar. No ar, essas vibrações chegam aos nossos ouvidos e podem ser percebidas como sons.

FrequênciaRelaciona-se à quantidade de vibrações por segundo. É medida em hertz (Hz) e está ligada à percepção de sons graves e agudos.
IntensidadeEstá relacionada à energia da onda sonora e à percepção de sons mais fracos ou mais fortes.
Decibel (dB)Unidade utilizada para expressar níveis sonoros em uma escala logarítmica.
Altura do somUm som grave tem frequência menor; um som agudo tem frequência maior.
Não confunda: grave e agudo descrevem a frequência do som. Fraco e forte descrevem sua intensidade percebida. São características diferentes.

👂 Audição, ruído e qualidade de vida

A audição permite perceber sons e participar de situações de comunicação. A exposição a sons muito intensos ou por períodos prolongados pode prejudicar a saúde auditiva.

Ambientes ruidosos também podem dificultar a concentração, a compreensão da fala e o descanso, além de provocar desconforto e estresse em algumas pessoas.

Acessibilidade auditiva

Algumas pessoas, incluindo algumas pessoas autistas, podem apresentar maior sensibilidade a determinados estímulos sonoros. Isso varia de pessoa para pessoa. Por isso, é importante pensar em espaços que ofereçam conforto e diferentes formas de comunicação.

Possíveis dificuldades

Ruídos intensos, conversas simultâneas e reverberação podem dificultar a compreensão de informações e gerar desconforto.

Cuidados e inclusão

Reduzir ruídos desnecessários, oferecer sinalização visual e disponibilizar espaços tranquilos pode favorecer a participação de mais pessoas.

Análise dos resultados

O maior valor registrado foi no pátio, com 81 dB. A quadra apresentou 75 dB e o corredor, 71 dB. Os menores valores foram registrados na biblioteca e no refeitório, ambos com 50 dB.

As diferenças podem estar relacionadas às atividades realizadas em cada local. No pátio havia pessoas conversando, na quadra havia uma turma na arquibancada e no corredor as portas das salas estavam abertas durante as aulas. A biblioteca estava quieta e o refeitório estava vazio.

Limitações: o aplicativo utiliza o microfone do celular e não substitui um equipamento profissional de medição acústica. Os resultados podem variar conforme o aparelho, a posição, a distância e as condições do ambiente. As medições representam registros pontuais, não uma avaliação completa da exposição sonora.

🌿 Propostas de melhoria

01

Materiais que absorvem o som

Estudar a utilização de materiais acústicos adequados em locais como quadras e refeitórios. Eles podem ajudar a reduzir a reverberação e melhorar o conforto sonoro.

02

Organização dos espaços

Quando possível, manter as portas das salas fechadas durante as aulas e organizar atividades em horários e espaços adequados pode ajudar a diminuir a propagação de ruídos pelo corredor.

03

Espaço tranquilo e sinalização visual

Disponibilizar um ambiente mais silencioso e utilizar placas visuais para orientar a comunidade escolar pode favorecer pessoas que precisam de menos estímulos sonoros.

🧠 Uso crítico da Inteligência Artificial

A Inteligência Artificial pode auxiliar na organização de ideias, na explicação de conceitos e na construção de materiais informativos. Entretanto, as informações precisam ser verificadas em fontes confiáveis e adaptadas com compreensão própria.

As medições apresentadas são os registros da atividade. A IA não deve ser apresentada como responsável por realizar medições físicas no ambiente.

Atividade 1 — Cofre Digital de Saúde e Emergência Médica

O objetivo foi desenvolver um programa interativo em Python capaz de cadastrar informações pessoais críticas (nome, tipo sanguíneo, alergias, medicamentos, contato de emergência, médico e plano de saúde) e armazená-las protegidas por senha no arquivo cofre_saude.txt.

Conceitos de Segurança & Criptografia

  • Hash & SHA-256: Transforma dados em uma assinatura de 256 bits para verificação.
  • PBKDF2: Deriva chaves seguras combinando a senha, um valor aleatório (sal) e 200.000 iterações.
  • HMAC: Garante a integridade e autenticidade, impedindo que dados adulterados sejam abertos.
  • XOR & Base64: Operação lógica de transformação binária e codificação textual para armazenamento em JSON.

Limitações e Uso Ético

Esta implementação possui finalidade didática. O uso de XOR com fluxo derivado de SHA-256 e Base64 não substitui bibliotecas profissionais de criptografia autenticada (como AES-GCM). Por isso, o programa deve ser testado apenas com dados fictícios.

Código Python — Cofre Digital (Cofre_Digital.ipynb) 
import json
import os
import base64
import hashlib
import hmac
import getpass

ARQUIVO = "cofre_saude.txt"
ITERACOES = 200_000

def gerar_chaves(senha, sal):
    chaves = hashlib.pbkdf2_hmac("sha256", senha.encode("utf-8"), sal, ITERACOES, dklen=64)
    return chaves[:32], chaves[32:]

def gerar_fluxo(chave, tamanho):
    fluxo = b""
    contador = 0
    while len(fluxo) < tamanho:
        bloco = hmac.new(chave, contador.to_bytes(8, "big"), hashlib.sha256).digest()
        fluxo += bloco
        contador += 1
    return fluxo[:tamanho]

def aplicar_xor(dados, chave):
    fluxo = gerar_fluxo(chave, len(dados))
    return bytes(a ^ b for a, b in zip(dados, fluxo))

def criptografar(dados, senha):
    sal = os.urandom(16)
    dados_bytes = dados.encode("utf-8")
    chave_criptografia, chave_integridade = gerar_chaves(senha, sal)
    dados_protegidos = aplicar_xor(dados_bytes, chave_criptografia)
    assinatura = hmac.new(chave_integridade, sal + dados_protegidos, hashlib.sha256).digest()

    pacote = {
        "sal": base64.b64encode(sal).decode("utf-8"),
        "dados": base64.b64encode(dados_protegidos).decode("utf-8"),
        "assinatura": base64.b64encode(assinatura).decode("utf-8")
    }
    return json.dumps(pacote)

def descriptografar(conteudo, senha):
    pacote = json.loads(conteudo)
    sal = base64.b64decode(pacote["sal"])
    dados_protegidos = base64.b64decode(pacote["dados"])
    assinatura_original = base64.b64decode(pacote["assinatura"])

    chave_criptografia, chave_integridade = gerar_chaves(senha, sal)
    assinatura_calculada = hmac.new(chave_integridade, sal + dados_protegidos, hashlib.sha256).digest()

    if not hmac.compare_digest(assinatura_original, assinatura_calculada):
        raise ValueError("Senha incorreta ou dados alterados.")

    dados_bytes = aplicar_xor(dados_protegidos, chave_criptografia)
    return dados_bytes.decode("utf-8")

Atividade 2 — Engenharia de Prompt e Leitura Facilitada com IA

Investigamos como pequenas mudanças nas instruções dadas a um Modelo de Linguagem (LLM) alteram a acessibilidade de textos científicos.

Texto Científico Original:

“A fotossíntese é um processo bioquímico realizado pelos organismos autotróficos, no qual a energia luminosa é convertida em energia química, permitindo a produção de compostos orgânicos a partir de água e dióxido de carbono.”

Experimento 1: Prompt Simples

Comando: “Explique esse texto de uma maneira mais simples e fácil de entender.”

Resposta da IA: “A fotossíntese é o processo pelo qual as plantas usam a luz do Sol, a água e o gás carbônico para produzir seu próprio alimento.”

Análise: Resposta curta e direta, mas omitiu conceitos importantes como "energia química" e "outros organismos" além das plantas.

Experimento 2: Prompt Detalhado

Comando: “Reescreva o texto utilizando palavras simples e frases curtas. Explique os termos científicos de maneira fácil, mantenha as informações principais do texto original e não acrescente informações que não estejam presentes nele.”

Resposta da IA: “A fotossíntese é um processo realizado pelas plantas e outros organismos. Nesse processo, eles utilizam a luz para produzir energia química. Para isso, usam água e gás carbônico e produzem substâncias orgânicas.”

Análise: Preservou o rigor científico do texto original mantendo a linguagem acessível.

Projeto 1 — Matriz de LEDs 8×8 (Comunicação Visual)

A matriz possui 64 LEDs organizados em 8 linhas e 8 colunas. Usando código binário (1 para ligado e 0 para desligado) e as bibliotecas LedControl e MatrizLed, exibimos um rosto expressivo e a frase deslizante "Como estou me sentindo".

  • Pinos do Arduino: Pino 8 (Dados), Pino 10 (Clock), Pino 9 (Seleção CS).
  • Acessibilidade: Ajuda na expressão de emoções e alertas visuais em locais barulhentos ou para pessoas surdas.
  • Limitação: Tamanho reduzido limita textos longos e exige compreensão prévia dos símbolos.
Código Arduino — Matriz de LEDs 8×8 
#include <LedControl.h>
#include <MatrizLed.h>

LedControl led = LedControl(8, 10, 9, 1);
MatrizLed displayLCD;
String figure_1 = "0011110001000010101010011000010110000101101010010100001000111100";

void setup() {
  led.shutdown(0, false);
  displayLCD.begin(8, 10, 9, 1);
  displayLCD.rotar(false);
  while(1) {
    displayLCD.borrar();
    displayLCD.escribirFraseScroll("Como estou me sentindo", 50);
    for (int counter = 0; counter < 8; counter++) {
      String figure2 = figure_1.substring(counter * 8, (counter + 1) * 8);
      for (int counter2 = 0; counter2 < 8; counter2++) {
        led.setLed(0, counter, 7 - counter2, figure2.substring(counter2, counter2 + 1) == "1");
      }
    }
    delay(3000);
  }
}

Projeto 2 — Botão, LED e Buzzer (Estudo do Código Morse)

O Código Morse representa letras por sinais curtos (pontos) e longos (traços), como o pedido de socorro SOS (··· −−− ···). No nosso circuito manual, ao pressionar o botão (INPUT_PULLUP), o LED acende e o buzzer emite um som de 800 Hz simultaneamente.

  • Pinos do Arduino: Pino 2 (Buzzer), Pino 3 (Botão), Pino 4 (LED).
  • Acessibilidade: Combina estímulo visual (luz) e sonoro (áudio), atendendo diferentes canais sensoriais.
  • Limitação: Exige acionamento manual, conhecimento do código e pode causar desconforto em pessoas com hipersensibilidade sonora ou fotossensibilidade.
Código Arduino — Código Morse 
int buzzer = 2;
int botao = 3;
int LED = 4;

void setup() {
  pinMode(buzzer, OUTPUT);
  pinMode(LED, OUTPUT);
  pinMode(botao, INPUT_PULLUP);
}

void loop() {
  if (digitalRead(botao) == LOW) {
    digitalWrite(LED, HIGH);
    tone(buzzer, 800);
  } else {
    digitalWrite(LED, LOW);
    noTone(buzzer);
  }
}

Projeto 3 — Display LCD 16×2 (Comunicação Textual)

O display LCD de 16 colunas e 2 linhas exibe mensagens escritas e recebe novos textos via Monitor Serial. Usamos um potenciômetro para ajustar o contraste da tela e os comandos especiais % (limpar tela) e > (pular para a segunda linha).

  • Pinos do Arduino: RS (12), E (11), D4 (5), D5 (4), D6 (3), D7 (2).
  • Acessibilidade: Ideal para orientações escritas em hospitais, escolas e atendimentos públicos.
  • Limitação: Tela pequena e caracteres fixos não atendem pessoas cegas (que precisam de leitores de tela ou áudio) nem quem tem baixa visão severa.
Código Arduino — Display LCD 16×2 
#include <LiquidCrystal.h>

LiquidCrystal lcd(12, 11, 5, 4, 3, 2);

void setup() {
  Serial.begin(9600);
  lcd.begin(16, 2);
  lcd.clear();
  lcd.setCursor(0, 0);
  lcd.print("but cute");
  lcd.setCursor(0, 1);
  lcd.print("eu amo 67...");
}

void loop() {
  if (Serial.available() > 0) {
    char cr = Serial.read();
    if (cr == '%') {
      lcd.clear();
      lcd.setCursor(0, 0);
    } else if (cr == '>') {
      lcd.setCursor(0, 1);
    } else {
      lcd.print(cr);
    }
  }
}

FÍSICA E TECNOCIÊNCIA — Ciência do Som e Acessibilidade

Investigação sobre ondas sonoras, audição humana, níveis de ruído na escola e estratégias de conforto acústico e inclusão sensorial.

Conceitos Físicos do Som e Audição

Propagação, Frequência e Intensidade

  • O que é o som: Uma onda mecânica produzida pela vibração de um corpo que precisa de um meio material (ar, água ou sólidos) para se propagar — não se propaga no vácuo.
  • Frequência (Hz): Número de oscilações por segundo. Define se o som é grave (baixa frequência) ou agudo (alta frequência). A audição humana típica vai de 20 Hz a 20.000 Hz.
  • Intensidade e Decibéis (dB): Relacionada à energia da onda (som fraco ou forte). A escala em dB é logarítmica, ou seja, 80 dB não é apenas o dobro da energia de 40 dB.

Saúde Auditiva e Hipersensibilidade

As ondas fazem o tímpano vibrar até a cóclea, onde viram sinais nervosos. A exposição prolongada a ruídos altos causa estresse, irritação, dificuldade de concentração e danos auditivos.

Além disso, pessoas com hipersensibilidade auditiva (como algumas pessoas autistas) podem sentir intenso desconforto em ambientes ruidosos ou com reverberação, tornando o conforto acústico uma questão de inclusão.

Propostas de Melhoria para o Conforto Acústico Escolar

1. Materiais de Absorção Sonora

Instalar painéis acústicos na quadra coberta e no refeitório para reduzir a reflexão e a reverberação das ondas sonoras.

2. Organização de Ambientes e Portas

Manter as portas das salas fechadas durante explicações e escalonar horários de atividades ruidosas nos corredores.

3. Espaço de Descompressão Sensorial

Criar uma sala tranquila com baixo estímulo sonoro e regras claras de silêncio para estudantes com hipersensibilidade auditiva.

4. Sinalização Visual Complementar

Acompanhar sinais sonoros (como o sinal de troca de aulas) com alertas visuais e placas informativas.
